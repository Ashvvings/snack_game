# Variante 2 : jeu de "Snake" classique avec bords fermés

Le code contenu dans le fichier `program.fl` de ce dossier représente la configuration d'un jeu de "Snake" avec bords fermés, avec un serpent ayant une longueur de 3 cases, une grille de 10 cases de long par 9 cases de large, et un fruit déjà présent.  
Manger un fruit avec le serpent augmente le score de 1, et allonge le serpent d'une case.  
Les fruits mangés réapparaissent sur une case vide aléatoire 2 secondes après qu'ils soient mangés.  
Rentrer en contact avec un bord de la grille met fin au jeu.
