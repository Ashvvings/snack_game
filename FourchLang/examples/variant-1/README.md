# Variante 1 : jeu de "Snake" classique

Le code contenu dans le fichier `program.fl` de ce dossier représente la configuration d'un jeu de "Snake" classique, avec un serpent ayant un longueur totale de 3 cases, une grille de 10 cases de long par 9 cases de large, et un fruit déjà présent.  
Manger un fruit avec le serpent augmente le score de 1, et allonge le serpent d'une case.  
Rentrer en contact avec une case ou se trouve le serpent met fin au jeu.
Les bordures de la grille sont traversables, faisant réapparaitre le serpent de l'autre côté s'il passe dans une bordure.  
Les fruits réapparaissent dans une case vide dès qu'ils sont mangés par le serpent.
