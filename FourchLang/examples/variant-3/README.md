# Variante 3 : jeu de "Snake" avec ennemis Snake

Le code contenu dans le fichier `program.fl` de ce dossier ressemble à la configuration d'un jeu de "Snake" classique avec un serpent ayant un longueur de 4 cases, une grille de 10 cases de long par 9 cases de large, et un fruit déjà présent.  
La différence avec le "Snake" classique est l'ajout d'un ennemi qui est lui aussi un serpent de longueur de 4 cases.  
Manger un fruit avec le serpent augmente le score de 1, qui réapparait dans une case vide dès qu'il est mangé.  
Les bordures de la grille peuvent être traversées, faisant réapparaitre les serpents à l'opposé de la grille.  
Rentrer en contact avec une case où se trouve un serpent (allié ou ennemi) met fin au jeu.
